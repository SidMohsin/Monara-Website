# MONARA Productions website

Marketing site for MONARA Productions, Sri Lanka. Built with Next.js 16 (App Router), React 19, plain JavaScript and Tailwind CSS 4. The deploy target is Vercel.

## Run it

```bash
npm install
npm run dev               # http://localhost:3000
npm run build && npm start
npm run lint
npm run assets:checklist  # regenerate Docs/asset-checklist.md
```

## Where things live

| What | File |
|---|---|
| Business details, navigation, brand lines (**placeholders marked `PLACEHOLDER`**) | `src/content/site.js` |
| Page copy (**drafts marked `draft: true`**) | `src/content/copy.js` |
| Services: 9 capabilities, groups and services (generated from the workbook) | `src/content/services.js` |
| Projects (currently placeholders) | `src/content/work.js` |
| **Every image and video slot** | `src/content/media.js` |
| Optional founder/team block (hidden while empty) | `src/content/team.js` |
| Design tokens (colours, type, motion) | `src/app/globals.css` |
| Logo files (temporary traces) | `public/brand/*.svg` |

### Common edits

- **Replace a placeholder image:** put the file in `public/media/`. Then, in `src/content/media.js`, set that slot's `src`, `alt` and `status: "final"`, and run `npm run assets:checklist`.
- **Add the hero video:** set `src` (an MP4) and `poster` on the `home-hero` slot.
- **Edit services:** edit the workbook, then run `python scripts/build-services.py "Docs/Monara productions_Service_Categorization_final.xlsx"`. The script needs the `openpyxl` Python package.
- **Add a real project:** add an entry to `src/content/work.js` with `placeholder: false`, plus its media slots.

## Environment variables

See `.env.example`.

| Variable | Effect |
|---|---|
| `NEXT_PUBLIC_SITE_URL` | Optional override for the canonical domain. Not needed on Vercel: production builds use `site.url` (`https://monaraproductions.com`, in `src/content/site.js`) and are indexable; preview and local builds stay `noindex`, block crawlers in `robots.txt`, and have no canonical URLs or sitemap entries. |
| `NEXT_PUBLIC_FORM_ENDPOINT` | Optional override for the contact form's endpoint (the Formspree URL is set in `src/content/site.js`). |
| `NEXT_PUBLIC_SHOW_DRAFTS` | Set to `true` to show "Draft" badges on text awaiting approval. |

## Project docs

The `Docs/` folder (client workbook, internal notes, review screenshots) is kept locally and is not published in this repository.

- `Docs/design-plan.md`: approved design direction and sitemap
- `Docs/client-checklist.md`: what we have, what is drafted, and what is still needed from the client
- `Docs/asset-checklist.md`: every image slot (generated)
- `Docs/screenshots/`: review screenshots

`AGENTS.md` is generated by `next dev` and points coding agents at the version-matched Next.js docs.
